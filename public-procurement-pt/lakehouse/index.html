How the data flows

What I built

  1. Ingestion that only reads what is new

    A Lakeflow pipeline uses Auto Loader to pick up the yearly files from a Unity Catalog volume. When a new file arrives, only that file is read. Bronze keeps every column as text, so a malformed date or amount never breaks the load.

  2. Cleaning with measured quality rules

    Silver removes duplicates and types every column in PySpark. Rows that break a hard rule (no contract id, no date) go to a rejected table with the name of the rule. Softer rules only count failures, so the quality of the source is visible on every run.

  3. Business rules in dbt

    dbt-databricks builds the gold layer: six dimensions, a fact table of contracts, a contract–supplier bridge and the marts behind each chart. 17 tests run on every refresh, including one that compares the totals with the original DuckDB build.

  4. Privacy by design

    Suppliers who are private individuals are masked before gold, and Genie only sees gold. Ask for the largest suppliers and the answer names companies only.

  5. One deploy, one schedule

    A Databricks Asset Bundle deploys the schemas, the pipeline, the weekly job and the dashboard with one command. The PySpark code has 13 unit tests that run in GitHub Actions without a workspace.

Two bugs the migration caught

  • A loader turned the "\b" in my regular expressions into a backspace character. Every municipality silently fell into "Other", and the totals still matched. A test now fails if that happens again.
  • Spark rounds divisions of decimals to six places, which changed a market-concentration index from 59.0 to 58.3. Shares are now computed in floating point.

The dashboard and Genie live inside my Databricks workspace, which Free Edition does not let me share publicly. That is why this page shows a video and screenshots instead of a live link. The code deploys to any workspace with one command.
