Does one more bidder lower the price? Competition in Portuguese public tenders¶

Question. In open tenders and prior consultations, how much lower is the signed price, relative to the procedure's base price, when more companies bid? And how often does a tender get only one bid?

Data. 1.55 million public contracts published on Portal BASE (IMPIC), January 2019 to 24 October 2026, the same raw files the dbt project uses. This notebook works from the raw Parquet files in pandas, independently of the SQL models, and checks that both give the same totals.

Short answer (the numbers are computed below):

  • With a single bid, open tenders sign at a median 99.3% of the base price. With ten or more bids, at 79.4%.
  • After controlling for category, year, contract type and contract size, each doubling of the number of bidders goes with a price about 5.7% lower (open tenders and prior consultations together).
  • Single-bid tenders are becoming more common: 9.0% of open tenders in 2019, 12.6% in 2025; for prior consultations 35.6% to 47.0%.

This is descriptive analysis of published records. It shows associations; it does not say that any buyer or supplier acted wrongly, and it does not prove that adding bidders causes lower prices (see the last section).

Run it: pip install pandas pyarrow matplotlib statsmodels, put the Portal BASE files in data/raw/ (see scripts/get_data.py) and run all cells (about 2 minutes).

1. Load and clean the raw files¶

Every column in the source is text. The cleaning follows the same rules as the dbt staging model stg_contracts.sql:

  • empty strings and the ∅ placeholder become missing values;
  • 4,566 contract ids appear twice inside the same yearly file; one row per id is kept (latest file first);
  • amounts use . as decimal separator; negative prices are treated as missing;
  • the number of bidders is the number of lines in concorrentes (it is only reported for some procedures).

Names of suppliers and descriptions of contracts are not used anywhere in this notebook.

3. Signed price against base price, by number of bidders¶

The base price is the maximum the buyer is willing to pay, set before bids arrive. The ratio signed price / base price is the share of that ceiling the buyer ends up paying: 1.00 means it paid the full ceiling, 0.80 means a 20% discount.

Same rules as the dbt mart mart_price_vs_base: only procedures with a single contract (a multi-lot procedure publishes one base price for all its lots), both prices above zero, and ratios between 0.2 and 5 (outside that range the base price is almost always mistyped).

The fall is steady: every extra bid lowers the median price. But the comparison above mixes very different contracts. Road works get more bidders than hospital software, and large contracts attract more bidders than small ones. The regression below holds those differences constant.

4. Regression: the price effect of more bidders, other things equal¶

$$\log\left(\frac{\text{signed price}}{\text{base price}}\right) = \beta \cdot \log(\text{bidders}) + \gamma \cdot \log(\text{base price}) + \text{procedure} + \text{CPV division} + \text{year} + \text{contract type} + \varepsilon$$

With both sides in logs, $2^{\beta} - 1$ is the change in price when the number of bidders doubles. Standard errors are robust to heteroscedasticity (HC1).

In [11]:
sample["log_ratio"] = np.log(sample["price_ratio"])
sample["log_bidders"] = np.log(sample["bidders"])
sample["log_base"] = np.log(sample["base_price"])

FE = "C(procedure_group) + C(cpv_division) + C(year) + C(contract_type)"
model = smf.ols(f"log_ratio ~ log_bidders + log_base + {FE}", data=sample).fit(cov_type="HC1")

beta, se = model.params["log_bidders"], model.bse["log_bidders"]
print(f"beta = {beta:.4f} (s.e. {se:.4f}), n = {int(model.nobs):,}, R² = {model.rsquared:.3f}")
print(f"Doubling the number of bidders: {2 ** beta - 1:+.1%} on the price "
      f"(95% CI {2 ** (beta - 1.96 * se) - 1:+.1%} to {2 ** (beta + 1.96 * se) - 1:+.1%})")

beta = -0.0842 (s.e. 0.0007), n = 272,342, R² = 0.132

# Same model with one dummy per bid count (1 bid is the reference), to see the shape without assuming a log curve
sample["bids"] = sample["bidders"].clip(upper=6).astype(int).astype(str).replace("6", "6+")
dummies = smf.ols(f"log_ratio ~ C(bids) + log_base + {FE}", data=sample).fit(cov_type="HC1")

effects = pd.DataFrame({
    "price_vs_single_bid": np.exp(dummies.params.filter(like="C(bids)")) - 1,
    "ci_low": np.exp(dummies.conf_int().filter(like="C(bids)", axis=0)[0]) - 1,
    "ci_high": np.exp(dummies.conf_int().filter(like="C(bids)", axis=0)[1]) - 1,
})

What this does not show¶

  • Not causal. Tenders that attract one bid may be different in ways the data do not record (a very specific specification, a remote location, a short deadline). Part of the gap may come from those differences, so the €-figure above is an upper-bound illustration, not money that was lost.
  • Base prices are set by the buyer. A buyer that sets a generous base price will see bigger "discounts". The CPV, year and size controls absorb part of this, not all of it.
  • Bidders are as reported. The count comes from the concorrentes field; it is missing for most direct awards and the notebook leaves those out.
  • The sample is single-contract procedures with a plausible base price (counted in the cell below), so multi-lot tenders are left out.

Next steps that would sharpen this: buyer fixed effects (does the same buyer pay less when more firms bid?), and the announcements dataset, to measure how long each tender was open.
